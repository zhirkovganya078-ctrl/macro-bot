# Macro Bot — макрос-бот для Windows с меню

Окно-меню, в котором вы собираете сценарий: клики по заданным координатам, нажатия клавиш/хоткеев и паузы. Бот проигрывает сценарий нужное число раз — например, ведёт игрока по точкам и жмёт нужные клавиши.

## Файлы

- `macro_bot.py` — основная программа с графическим меню (tkinter).
- `macro_cli.py` — консольная версия: запись действий целиком и воспроизведение по хоткеям.
- `vision_bot.py` — ИИ-зрение: бот находит цель на скриншоте через нейросеть и реагирует (см. ниже).

## ИИ-зрение: vision_bot.py

Бот периодически снимает экран, отправляет скриншот vision-модели (Mistral) и спрашивает, видна ли цель. Если цель найдена — кликает по её центру и/или жмёт заданные клавиши.

1. Получите бесплатный API-ключ на [console.mistral.ai](https://console.mistral.ai) (ключ хранится локально в `vision_config.json`, в git не попадает).
2. Запуск: `python vision_bot.py` (от имени администратора).
3. Вставьте API-ключ в меню.
4. (Рекомендуется) Нажмите **«Захватить образец»** — у вас 3 секунды, чтобы открыть окно игры, затем обведите цель мышью. Скриншот-образец сохранится в `reference.png` и сильно повысит точность.
5. Опишите цель текстом: что искать (например, «красная кнопка «Продать»» или «враждебный моб с синей подсветкой»).
6. Настройте реакцию: клик по центру цели (ЛКМ/ПКМ/СКМ) и/или нажатие клавиш через запятую (`e, space`).
7. Задайте интервал проверки (по умолчанию 3 сек) и нажмите **«Запустить слежение»**. F12 — аварийный стоп.

Примечания:

- Нужен интернет: каждый запрос отправляет скриншот в Mistral API (на бесплатном тарифе есть лимиты запросов).
- Задержка реакции 1–3 секунды — это стандартная скорость vision-модели.
- Модель возвращает координаты в долях экрана, поэтому разрешение и масштаб не важны.

## Установка

1. Установите Python 3.10+ с python.org (tkinter входит в комплект).
2. В командной строке в папке проекта:
   ```
   pip install -r requirements.txt
   ```
3. Запуск **от имени администратора** (иначе игры могут игнорировать ввод):
   ```
   python macro_bot.py
   ```

## Как пользоваться меню

### Найти координаты
- Вверху окна всегда показаны **текущие координаты курсора** — наведите мышь на нужную точку в игре и посмотрите цифры.
- Или нажмите **«Взять координаты курсора (3 сек)»** — у вас есть 3 секунды, чтобы навести мышь на цель; координаты сами подставятся в поля X/Y.
- Затем нажмите **«Добавить клик»** — выбрав кнопку мыши (ЛКМ/ПКМ/СКМ).

### Задать хоткей
- Впишите название клавиши (`e`, `space`, `ctrl+shift+s`) или нажмите **«Снять клавишу»** и нажмите нужное сочетание на клавиатуре.
- **«Добавить клавишу»** — добавит нажатие в сценарий.

### Порядок и запуск
- Сценарий — список шагов **сверху вниз**: клик → пауза → клавиша → клик…
- **↑ Выше / ↓ Ниже** меняют порядок шага, **Удалить / Очистить всё** убирают лишнее.
- «Повторов» — сколько раз прогнать сценарий; «Скорость» — ускорение пауз (2.0 = вдвое быстрее).
- **▶ Старт** — запустить, **■ Стоп** — остановить. Глобальная клавиша **F12** — экстренная остановка из любого приложения.
- **● Запись** — живая запись ваших кликов и нажатий в шаги сценария (с паузами), стоп — F8 или кнопкой.
- **Сохранить / Загрузить** — сценарий хранится в `macro.json` и подхватывается при запуске.

## Консольная версия (macro_cli.py)

| Клавиша | Действие |
|---------|----------|
| **F8** | Начать / остановить запись |
| **F9** | Воспроизвести |
| **F10** | Сохранить в `macro.json` |
| **F12** | Аварийный стоп |
| **Ctrl+Esc** | Выход |

## Замечания

- Синтетический ввод работает в большинстве игр, но окно игры должно быть активно во время воспроизведения.
- Между нажатием и отпусканием есть пауза 30 мс — многие игры требуют этого, чтобы «увидеть» ввод.
- Если игра защищена античитом (BattlEye, EAC и т. п.), макросы могут привести к бану — используйте только там, где это разрешено.
