# AHK Bot

Простой бот-окно, который повторяет AutoHotkey-скрипт: действия запускаются от колёсика мыши и средней кнопки.

## Триггеры

| Действие | Что делает |
|---|---|
| **Колёсико ВНИЗ** | нажимает `Alt` |
| **Колёсико ВВЕРХ** | клик в точку (X, Y), держит `S` 1 сек, держит `W` 1 сек, снова клик в (X, Y) |
| **Средняя кнопка (нажатие колёсика)** | клик ЛКМ → 4× зажать ПКМ на 2 сек → 36 быстрых кликов ЛКМ (10 мс) → 4× зажать ПКМ на 1.7 сек |

Каждый триггер включается/выключается галочкой. Точку клика для колёсика вверх можно менять полями X / Y (по умолчанию 1150, 380).

## Управление окном

- Окно всегда **поверх всех окон** (галочку можно снять)
- **Ins** — скрыть/показать окно (бот продолжает работать)
- **F12** — аварийная остановка выполняющейся последовательности
- Журнал внизу показывает, что бот выполнил

## Установка и запуск

```
pip install -r requirements.txt
python macro_bot.py
```

Запускайте **от имени администратора**, если игра игнорирует нажатия.

## Как повторить ваш AutoHotkey-скрипт

Скрипт уже встроен один в один:

- `Wheeldown:: Send {alt}` → триггер «Колёсико ВНИЗ»
- `WheelUp:: MouseMove 1150,380 + ЛКМ + S 1000мс + W 1000мс + клик` → триггер «Колёсико ВВЕРХ» (тайминги пауз совпадают: 50/100/100/1000/100/1000/50/100/100/100 мс)
- `MButton::` → «Средняя кнопка»: ЛКМ → ПКМ 2000мс ×4 → ЛКМ ×36 с паузой 10мс → ПКМ 1700мс ×4

Защита от задвоения: пока триггер выполняется, повторное нажатие того же триггера игнорируется.

## Предупреждение

Использование ботов может нарушать правила игры и приводить к блокировке аккаунта.
