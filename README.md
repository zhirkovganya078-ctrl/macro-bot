# Macro Bot — макрос-бот для Windows с меню

Окно-меню, в котором вы собираете сценарий: клики по заданным координатам, нажатия клавиш/хоткеев и паузы. Бот проигрывает сценарий нужное число раз — например, ведёт игрока по точкам и жмёт нужные клавиши.

## Файлы

- `macro_bot.py` — основная программа с графическим меню (tkinter).
- `macro_cli.py` — консольная версия: запись действий целиком и воспроизведение по хоткеям.

## Установка

1. Установите Python 3.10+ с python.org (tkinter входит в комплект).
2. В командной строке в папке проекта:
   ```
   pip install -r requirements.txt
   ```
3. Запуск **от имени администратора** (иначе игры могут игнорировать ввод):
   ```
   python macro_bot.py
   ```

## Как пользоваться меню

### Найти координаты
- Вверху окна показаны **текущие координаты курсора** — наведите мышь на точку и считайте цифры.
- Или нажмите **«Задать координаты по клику мыши»**: перейдите в игру и **кликните в нужном месте** — координаты сами подставятся в поля X/Y. Затем **«Добавить клик»** (ЛКМ/ПКМ/СКМ).

### Задать клавишу
- Нажмите **«Снять клавишу»**, затем физически нажмите нужную клавишу (`e`, `space`, `f`…) — она сама подставится в поле. Можно и вписать название вручную.
- **«Добавить клавишу»** — добавит нажатие в сценарий.
- Хоткеи-сочетания (Ctrl+…) не поддерживаются — только одиночные клавиши.

### Поиск на экране по образцу (объекты, которые меняют место)

Когда машина/деталь появляется в разных местах, фиксированные координаты не подходят. Используйте блок **«Найти объект на экране по образцу»**:

1. **«Снять рамкой»** — 3 секунды на переключение в игру, затем обведите нужный объект (болт, деталь, надпись события) мышью. Картинка сохранится в папку `templates/`.
2. Выберите действие: **«Кликнуть N раз»**, **«Удерживать»** (сек), **«Ждать появления»** — бот ждёт событие, не нажимая ничего, или **«Ждать и нажать клавишу»** — когда событие появится (например, окно награды), бот сразу жмёт заданную клавишу (по умолчанию `space`). В режимах ожидания поле «Сек» = максимальное ожидание.
3. **«Добавить «найти и нажать»** — перед каждым прогоном бот сам ищет объект на экране и действует по найденному месту.

Если объект не найден за таймаут — шаг пропускается, цикл продолжается.

### Действие до заполнения шкалы

Для механик вида «зажимайте ЛКМ, чтобы поставить колесо»: снимите точку шкалы кнопкой **«Снять цвет шкалы по клику»** (кликните в то место шкалы, которое красится при заполнении), задайте где нажимать, кнопку (ЛКМ), режим «Зажать» или «Клики» — и бот будет держать/кликать, пока шкала не заполнится (проверка цвета пикселя каждые 0.25 сек, со страховочным таймаутом).

### Запись действий

Кнопка **«● Запись»** считывает ваши реальные действия в шаги сценария: клики (с координатами), нажатия клавиш с продолжительностью удержания и паузы между действиями. Остановка — F8 или кнопкой.

### Новые типы шагов

- **Ходьба** — бот зажимает клавиши движения (например, `w` или `w+a`) на заданное число секунд, потом отпускает. Так он идёт в нужное место.
- **Повторные клики** — у клика есть поля «Раз» и «Интервал»: кликнуть по болту 10 раз с интервалом 0.5 сек — откручивание/закручивание болтов.
- **Удержание клавиши** — у клавиши есть поля «Раз» и «Удерживать, сек»: зажать `e` на 2 сек — осмотреть машину или взять деталь.

### Пример сценария «мастерская»

1. Ходьба `w` 4 сек — подойти к машине
2. Клавиша `e`, удерживать 2 сек — осмотреть машину
3. Клик по детали x1 — взять деталь
4. Ходьба `s+a` 3 сек — перейти в нужное место
5. Клик по болту x10 с интервалом 0.4 — открутить болты

Используйте «Задать координаты по клику мыши» для каждой точки и подбирайте секунды ходьбы опытным путём.

### Порядок и запуск
- Сценарий — список шагов **сверху вниз**: ходьба → пауза → клавиша → клик…
- **↑ Выше / ↓ Ниже** меняют порядок шага, **Удалить / Очистить всё** убирают лишнее.
- «Повторов» — сколько раз прогнать сценарий; «Скорость» — ускорение пауз (2.0 = вдвое быстрее).
- **▶ Старт** — запустить, **■ Стоп** — остановить. Глобальная клавиша **F12** — экстренная остановка из любого приложения.
- **● Запись** — живая запись ваших кликов и нажатий в шаги сценария (с паузами), стоп — F8 или кнопкой.
- **Сохранить / Загрузить** — сценарий хранится в `macro.json` и подхватывается при запуске.

## Консольная версия (macro_cli.py)

| Клавиша | Действие |
|---------|----------|
| **F8** | Начать / остановить запись |
| **F9** | Воспроизвести |
| **F10** | Сохранить в `macro.json` |
| **F12** | Аварийный стоп |
| **Ctrl+Esc** | Выход |

## Замечания

- Синтетический ввод работает в большинстве игр, но окно игры должно быть активно во время воспроизведения.
- Длительность ходьбы зависит от скорости персонажа в игре — подберите её тестовыми прогонами (Повторов = 1, Стоп по F12 при overshoot).
- Между нажатием и отпусканием есть пауза 30 мс — многие игры требуют этого, чтобы «увидеть» ввод.
- Если игра защищена античитом (BattlEye, EAC и т. п.), макросы могут привести к бану — используйте только там, где это разрешено.
